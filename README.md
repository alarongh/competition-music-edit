# Competition Music Edit

Скил для Codex, который помогает смонтировать готовый трек для соревнований, танца или другого выступления. Он подбирает места для сокращения или повтора, защищает вокал и музыкальный финал и проверяет длительность готового файла после экспорта.

## Установка в Codex

1. Скачайте или клонируйте репозиторий.
2. Скопируйте папку [`skills/competition-music-edit`](skills/competition-music-edit) целиком в `~/.agents/skills/` для всех проектов или в `.agents/skills/` в корне нужного проекта. Внутри скопированной папки должен остаться `SKILL.md`. См. [инструкцию OpenAI](https://developers.openai.com/api/reference/cli#installation) о расположении скилов.
3. Откройте новый чат Codex в нужном проекте. Пример запроса:

   > $competition-music-edit Сократи «трек.mp3» до 2:00. Сохрани первые восемь секунд, вокал и исходную музыкальную концовку.

Также можно задать диапазон: «Удлини трек до 2:15–2:20, повторив инструментальную фразу перед финалом».

Скил содержит инструкции для Codex. Для самого монтажа нужен доступ к исходнику и аудиоредактору или FFmpeg. Команды сборки и проверки находятся в [памятке по FFmpeg](skills/competition-music-edit/references/ffmpeg.md).
