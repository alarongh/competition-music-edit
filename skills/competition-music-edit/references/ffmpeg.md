# Точная сборка и проверка в FFmpeg

Используй эти команды, если есть FFmpeg с нужным кодировщиком и требуется точно уложиться во время. Музыкальные границы сначала выбери по исходнику. На выходе указывай новый путь; `-n` запрещает перезапись. `0:a:0` выбирает первую звуковую дорожку, поэтому при нескольких дорожках проверь, какая нужна.

## Длительность и стыки

- На частоте `R` Гц целевое число отсчётов на канал равно `round(секунды × R)`. Диапазон `[start, end)` имеет длину `end − start`. Суммируй длины сохраняемых и повторённых участков и вычитай длины всех перекрытий.
- Для точных границ `atrim` принимает `start_sample` и `end_sample`; после каждого фрагмента сбрасывай метки через `asetpts=PTS-STARTPTS`. Для перекрытия используй `acrossfade=ns=...`. Если выбран стык без перекрытия, склей фрагменты через `concat` и не вычитай длину кроссфейда.
- Например, при 48 кГц два участка `[0, 48000)` и `[69600, 96000)` с перекрытием в 2400 отсчётов дают `48000 + 26400 − 2400 = 72000` отсчётов, то есть 1,500 с. Значения ниже иллюстрируют арифметику, а не универсальные границы или длину кроссфейда.

```sh
ffmpeg -n -i "source.wav" -filter_complex "[0:a:0]asplit=2[a][b];[a]atrim=end_sample=48000,asetpts=PTS-STARTPTS[left];[b]atrim=start_sample=69600:end_sample=96000,asetpts=PTS-STARTPTS[right];[left][right]acrossfade=ns=2400[out]" -map "[out]" -c:a pcm_s24le "edit.wav"
ffmpeg -n -i "edit.wav" -map 0:a:0 -c:a libmp3lame -q:a 2 "edit.mp3"
```

## Проверь файл, который получит пользователь

Длительность контейнера MP3 может отличаться от фактической длительности декодированного звука из-за задержки кодера и дополнения кадров. Записывай MP3 в обычный файл с включённым по умолчанию заголовком Xing/LAME. Не вычитай задержку вручную из аудио, если декодер уже учёл её по метаданным.

Декодируй итоговый MP3 в новый временный WAV. Для моно или стерео следующий пример использует Python 3, чтобы посчитать отсчёты на канал и фактическое время. Сравнивай число отсчётов с целью на **частоте готового файла**, особенно если при экспорте она изменилась.

```sh
ffmpeg -n -v error -i "edit.mp3" -map 0:a:0 -c:a pcm_s16le "decoded-check.wav"
python -c "import sys,wave; w=wave.open(sys.argv[1]); n,r=w.getnframes(),w.getframerate(); print(f'{n} samples/channel at {r} Hz = {n/r:.6f} s'); w.close()" "decoded-check.wav"
ffmpeg -hide_banner -i "edit.mp3" -map 0:a:0 -af ebur128=peak=true -f null -
```

В итоговой сводке последней команды проверь `True peak`. Если экспорт близок к пределу или превышает его, оставь запас по уровню, экспортируй заново и повтори проверку. При жёстком регламенте и расхождении с плеером проверь именно плеер или формат, которым пользуются на площадке.

Документация: [фильтры FFmpeg](https://ffmpeg.org/ffmpeg-filters.html), [особенности записи MP3](https://ffmpeg.org/ffmpeg-formats.html#mp3).
